# VES Site Interpreter Pro

Free VES (Vertical Electrical Sounding) field app by Dr. Uche Aluge Daniel.

Open the app: https://dealphaseriezltd-ctrl.github.io/ves-site-interpreter-pro/

Log readings on site — automatic K and apparent resistivity, live log-log curve, AI curve interpretation, Pro recommendation with data quality score and depth guidance, GPS stations, voice notes, photos, Word-ready reports. Works offline once loaded.
